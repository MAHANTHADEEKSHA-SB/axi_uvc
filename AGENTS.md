# GitHub repository AI guidance

This repository holds the AXI UVC. Its `main` branch still carries an older flat-layout AXI UVC; on `dev`, PR #14 replaced it by an empty `src/`/`tb/` scaffold and an AXI decision log (`docs/ARCHITECTURE_DECISIONS.md`). On the owner's request the scaffold was refactored onto the architecture of the owner's APB and AHB UVCs: the UVC now lives in `poc/axi_uvc/`, and the placeholders were removed (`docs/dv-architecture/DIRECTORY_ARCHITECTURE.md` shows where each one went). The owner's site scripts under `scripts/` are not part of the UVC; do not change them.

For the **single AXI UVC proof of concept** under `poc/axi_uvc/`, start with [docs/dv-architecture/SESSION_SUMMARY.md](docs/dv-architecture/SESSION_SUMMARY.md) (orientation and a new-chat start prompt), then read [docs/dv-architecture/AGENTS.md](docs/dv-architecture/AGENTS.md) and its architecture contract, ADRs, directory plan, `WORK_STATUS.md`, and `REVIEW_FEEDBACK.md`. Owner decisions are in [docs/dv-architecture/DECISION_LOG.md](docs/dv-architecture/DECISION_LOG.md) — including the AXI decisions A-1..A-11 of PR #14 and the open proposals S-1..S-6 that change some of them; every code change must follow [docs/dv-architecture/CODING_GUIDELINES.md](docs/dv-architecture/CODING_GUIDELINES.md) (mandatory). These documents were adapted from the `apb_uvc` (`dev`, `b406d6a`) and `AHB-UVC` (`dev`, `73f7d33`) repositories on the owner's request.

The AXI UVC is self-contained: **one** signal interface per bus, **three** separate BFM interfaces (Manager, Subordinate, monitor), separate abstract/concrete HVL proxies (drive, respond, observe), UVM components of both roles, and filelists. The two width configurations are **instances of the same UVC** (ADR-001), and AXI4-Lite is a configuration mode of the same code.

Do not run any simulator, compiler, elaborator or lint tool, or add a tool option, without explicit owner approval; no tool-specific workarounds. Do not claim compilation or simulation passed without actual commands/logs. Do not modify the source outside `poc/axi_uvc/` unless separately approved; `docs/ARCHITECTURE_DECISIONS.md` is append-only. No force pushes or direct merges into `dev` or `main`.
